# Anatomy Diagrams Demo

Demo of the Anatomy Study Tool with only Chapters 6 and 7 diagrams.

## What's included
- Chapter 6: Bone shapes, fracture types
- Chapter 7: Axial skeleton overview, skull, vertebral column, thoracic cage

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Enable in Settings → Pages → Deploy from branch → main → / (root).
Site will be at: https://hmxxu.github.io/AnatomyDiagramsDemo/
